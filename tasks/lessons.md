# Lessons

## 2026-06-06 Rabbit Mail Master Update

- When the final product identity changes, update the document title, acceptance criteria, architecture, feature mapping, and task logs together.
- When migrating from a web-app stack to a native desktop stack, remove endpoint-first language and replace it with local IPC, Rust modules, and desktop runtime boundaries.
- Keep Canvas-based product concepts concrete by defining workspace components, state transitions, and inspection panels, not only visual mood.

## 2026-06-06 Detailed Design Part 3

- Keep detailed design numbering aligned with the user's latest requested part, even if earlier Next Steps named a different topic.
- For privacy-first mailer design, treat summaries, contextual hints, drafts, and lessons as sensitive derived data.
- Store sensitive derived data encrypted at rest, not only the original email body.
